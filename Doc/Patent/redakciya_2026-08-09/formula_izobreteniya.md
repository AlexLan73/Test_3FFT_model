# Формула изобретения (рабочий свод)

> Якорь пакета. Описание в заявках обязано поддерживать каждый признак формулы.
> Первоисточник точных формулировок — `zayavka_SPOSOB.md` и `zayavka_USTROJSTVO.md`;
> здесь — сжатый каркас для сверки и для работы с поверенным.
> Финальную редакцию визирует патентный поверенный.

## Обозначения

`Q` — число антенн (массив `Q·l`); `l` — комплексных отсчётов на антенну; `N` — отсчётов после дечирпа;
`i`, `j` — числа элементов решётки по двум осям апертуры (`Q = i·j`); `i_пад`, `j_пад` — размеры осей
после дополнения нулями до степени двойки; `M = i_пад·j_пад` — число угловых ячеек; `L` — глубина
объёмного участка; `D` — глубина участка группировки бинов дальности; `m` — нативный размер матричной
операции; `k_x`, `k_y` — номера угловых бинов; `K` — число гипотез задержки; `S` — число лучей опроса.

## Способ — 20 пунктов, два независимых (1 и 18)

### С.1 (независимый) — дальностно-разрешённый тракт

За каждый рабочий такт: **(а)** излучают широкий ЛЧМ, принимают элементами АФАР, дечирпируют с
получением `N` отсчётов и формируют массив «апертура×апертура×дальность» `i×j×N` **двумя раздельными
преобразованиями Фурье** — глобальным дальностным по быстрому времени и поячеечным угловым на каждом
бине; по каждой оси апертуры перед угловым преобразованием — **взвешивание по действительно имеющимся
элементам, затем дополнение нулями до степени двойки, затем своя угловая шкала**;
**(б)** полную угловую карту среза заменяют **структурным токеном** — ярчайшие пики + вектор
**страддл-инвариантных признаков**; **(в)** срез относят к классу **нейросетевым гейтом**, а
принадлежность истинной/ложной цели устанавливает **причинностный арбитр** (ближний член причинностной
группы при `τ ≥ 0` и/или согласование с текущим кодом); **(г)** по матрице токенов формируют
целеуказание и излучают многолучевой агильный ФМ-зонд с кодом переменной длины `2ⁿ`, меняющимся от
такта к такту.

> **Ядро новизны — совокупность (а)+(б)+(в)+(г).** Дробление недопустимо: каждый элемент по
> отдельности бьётся уровнем техники.

### Зависимые от С.1

|---|---|

| **3** | Устойчивое обнаружение пиков — OS-CFAR по угловой координате |
| **4** | Арбитр применяют в области **самозащитной** помехи; уводящую на ином носителе разделяют по свежести кода и угловому разнесению |
| **5** | Гейт — 3 класса (шум / собранный / размазанный); 4 класса сцены — вторым проходом по профилю токенов вдоль дальности |
| **6** | Корреляция через БПФ по `K` сопряжённым опорам для `S` лучей, батчинг по свободной памяти; на выходе ОБПФ — вторичные токены из 3–5 максимумов |
| **7** | На трудных кандидатах — резидентная сеть LSTM/GRU **над потоком токенов**, не над сырыми данными |
| **8** | Формирование **секции** углового среза, свёртку секции в токен и классификацию — **в памяти рабочей группы**, во внешнюю память выгружают **только токен**; размер секции согласован с нативным размером `m`; угловое преобразование — на **матричных блоках** |
| **9** (от 8) | При оси свыше `m` — **блочная раскладка**: нативные блоки + промежуточные поворачивающие множители + второй уровень сложения; число уровней = отношение размера оси к `m`; при оси не свыше `m` — одна матричная операция |
| **10** | Приём **несколькими каналами**, каждый сопряжён со своим вычислителем и берёт **свою подрешётку**, запись прямо в его память; дальностное БПФ — **параллельные** преобразования; по их завершении данные перераспределяют; **угловое преобразование не разделяют** — срез формируют целиком на одном вычислителе |
| **11** (от 10) | Перераспределение **порциями** с совмещением передачи очередной порции с обработкой предыдущей; размер порции — из условия «время передачи ≤ время обработки» |
| **12** (от 10) | Бины делят на **непрерывные блоки равной длины по номеру**; расписание задают до начала такта и в течение такта не пересчитывают |
| **13** (от 10) | Матрицы токенов сводят на **один выделенный вычислитель** — там арбитр и последовательностная сеть |
| **14** (от 10) | **Кластер**: вычислители группируют в **узлы**, соединённые сетью с прямым доступом к памяти; каждый узел принимает свою часть подрешёток своими каналами; **сырьё между узлами не передают**; межузловое перераспределение — по **тем же** правилам (непрерывные блоки, порции, статическое расписание); токены всех узлов — на один выделенный узел |
| **15** | Бины группируют в участки глубиной `D`; предварительное решение: складывают по дальности **поканально**, над суммарной выборкой — **одно** угловое преобразование, свёртка в **тот же** токен, отнесение **тем же** гейтом; шум не обрабатывают, отклик разбирают поячеечно по всем `D`. Поячеечная обработка — частный случай при `D = 1` |
| **16** (от 15) | Складывание = удержание **нулевого выхода** БПФ по оси дальности; `D` — наименьшее из ограничения по энергетическому запасу (убывает с дальностью) и по разрежённости (равенство затрат проходов при `D = √(N_бин/T)`) |
| **17** (от 10 и 15) | Складывание — **на том вычислителе, где канал принят, до обмена**; перераспределение **в два прохода**: суммарные выборки (объём меньше в `D` раз) → предварительное решение → полные данные **только** участков с откликом |

### С.18 (независимый) — объёмный примитив с переменной размерностью

Излучают зондирующий сигнал, размещают принятые данные в памяти ГПУ и **в пределах одного такта из
одних и тех же данных, не пересылая их повторно**, формируют объёмные участки `i×j×L` произвольного
размера, шага и положения, изменяя глубину `L` в течение того же такта: грубый проход участками
увеличенной глубины с 3D-БПФ → отбор ограниченного числа ярчайших выбросов → **тонкий добор ТЕХ ЖЕ
участков** участками уменьшенной глубины; каждый участок сворачивают в токен по признакам,
обобщённым на объём, с 3D-пороговым обнаружением; метку выносит **тот же** причинностный арбитр.

### Зависимые от С.18

| № | Признак |
|---|---|
| **19** (замок единства) | Объёмные признаки: лепесток 3×3×3, охрана 5×5×5, OS-CFAR по объёму; **токен совпадает** с токеном по п. 1; двумерная токенизация — **частный случай объёмной при `L = 1`**; 3D-БПФ по третьей оси удерживает **все** выходы, тогда как складывание по п. 15 удерживает **нулевой выход того же преобразования** |

## Карта «признак → уровень техники» (для поверенного)

- (а) два раздельных БПФ дальность/угол — близко: **EP0097490A2**, **CN101441271A**. Новизна не в самих двух БПФ.
- (б)+(в) ИИ-классификатор на радарном кубе — близко: **US10962637B2**, **US12181562**. Отличие — токен из страддл-инвариантных признаков + гейт/арбитр, а не end-to-end сеть.
- (г) целеуказание/планирование пучка ИИ — близко: **US11747438**. Отличие — управление именно агильным FM-m из матрицы токенов.
- п. 10–14: распределённое и кластерное исполнение — **близко: US11796628B2** и **US10627480B2** (TI, семья, приоритет 2014) — там угловое БПФ **централизовано** на выделенном процессоре, а отбор передаваемого делают пороговым обнаружением после полной обработки каналов; **CHIME Pathfinder / kotekan** (arXiv:1503.06189, 1503.06202, 2015) и **Tianlai** (arXiv:2406.19013) — corner-turn коммутируемой сетью, узлу — своя полоса, приём прямой записью в размеченное кольцо, но состав передачи **задан заранее** и от сцены не зависит. Отличие: там угловое БПФ **централизовано** на отдельном процессоре и обмен полный; у нас угловое БПФ **распределено**, централизован только арбитраж, а на него идут **токены**, и обмен **гейтируется** (п. 14, 16).
- п. 9: блочная раскладка — общеизвестный алгоритм (**Cooley–Tukey 1965**, **Bailey 1990**), заявляется **не сам алгоритм**, а его применение для удержания вычисления на нативном матричном блоке при апертуре произвольного размера; поэтому пункт зависимый от п. 8.
- п. 14, 17: грубый проход → отбор → тонкий добор — близко: **US11808881B2** (Arbe). Отличие: у нас **один** набор данных перенарезается, а не два кадра разного разрешения, и решение выносит тот же токен и тот же арбитр.
- Прототип: **RU2549375C1**.

**Вывод для защиты:** новизна держится на СОВОКУПНОСТИ. Отдельно взятые п. 9, 10–14 уязвимы —
их удерживают связкой с признаками (б) и (в) независимого пункта.
