# Архив редакций патентных документов

> **Соглашение:** старая редакция уходит сюда с суффиксом `_vN_<чем отличается>`,
> каноническое имя остаётся за текущей редакцией в `Doc/Patent/`. Так ссылки и картинки
> в рабочих файлах не ломаются.
>
> **Исключение — редакция в работе.** Пока редакция не согласована, она живёт в отдельной
> датированной папке рядом с каноном (см. ниже), а канон не трогается. В архив она попадёт
> только когда её сменит следующая.

---

## Текущее состояние на 2026-08-09

| Где | Что |
|---|---|
| `Doc/Patent/*.md` | **канон** — редакция «до N вычислителей», состояние коммита `3fbdf16` |
| `Doc/Patent/redakciya_2026-08-09/` | **редакция в работе** — распределённое исполнение на N вычислителях, `.md` + собранные `.docx` + сборщик. Не подана, см. её `00_README.md` |
| `Doc/Patent/_archive/` | эта папка — редакции, которые уже сменены |

Отдельного архива для «до N вычислителей» **не заведено намеренно**: она сейчас и есть
канон, дублировать нечего. Когда `redakciya_2026-08-09/` будет одобрена и поднята в канон,
текущие файлы уедут сюда как `*_v?_bez_NGPU.md`.
